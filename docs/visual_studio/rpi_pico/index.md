# Raspberry Pi Pico

The Raspberry Pi Pico development eco-system (SDK, tools, etc) are built using the CMake
build system.  The offical documentation contains references on how to use VSCode, but there
is very little info out there on how to build it using "full-fat" Visual Studio.
